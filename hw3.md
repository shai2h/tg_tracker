## Пункт 3 — Тесты

Пишем интеграционные тесты — поднимаем всё приложение, шлём HTTP запросы, проверяем что данные сохранились и читаются правильно. Никаких моков базы данных.

Для тестовой базы рекомендую **SQLite in-memory через `aiosqlite`** — не нужен Docker, поднимается мгновенно. Установи:

```
uv add --dev pytest pytest-asyncio httpx aiosqlite
```

Паттерн для `conftest.py`:

```python
@pytest.fixture
async def client():
    engine = create_async_engine("sqlite+aiosqlite:///:memory:")
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)

    def override_get_db():
        async with AsyncSession(engine) as session:
            yield session

    app.dependency_overrides[get_db] = override_get_db
    async with AsyncClient(app=app, base_url="http://test") as ac:
        yield ac
```

> **Нюанс:** SQLite не поддерживает UUID как нативный тип. Столкнёшься с ошибкой — разберись как решить (подсказка: `String` тип или `native_uuid=False`). Либо подними Postgres в Docker через `pytest` — тоже валидный выбор, объясни почему выбрал именно так.
